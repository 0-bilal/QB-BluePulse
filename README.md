# QB-BluePulse - نظام إدارة المسبح الذكي

![Version](https://img.shields.io/badge/version-3.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## 📋 نظرة عامة

QB-BluePulse هو نظام إدارة مسابح احترافي مصمم خصيصاً لأجهزة الهاتف المحمول. يوفر النظام واجهة سهلة الاستخدام لتتبع مهام صيانة المسبح وحساب الكميات المطلوبة من المواد الكيميائية.

## ✨ المميزات

### 🏊 إدارة المهام
- جدول صيانة شهري كامل (4 أسابيع)
- 16 مهمة محددة مسبقاً
- تتبع المهام المكتملة
- تصفية حسب الأسبوع

### 🧮 حاسبة المواد الكيميائية
- حساب تلقائي للكميات حسب حجم المسبح
- معدلات دقيقة لكل مادة:
  - **CLR 90** (عادي): 2.6 غ/طن
  - **CLR 90** (صدمة): 5 غ/طن
  - **TIRA POOL 40**: 2.4 مل/طن
  - **CLEAR POWER**: 5.2 مل/طن

### 📊 الإحصائيات
- عرض تقدم الإنجاز الفوري
- إحصائيات شاملة للمهام
- شريط تقدم متحرك

### 🎨 التصميم
- Dark Mode احترافي
- واجهة عربية كاملة
- تصميم متجاوب (9×16)
- أنيميشن سلس

## 🚀 التثبيت والاستخدام

### الطريقة 1: استخدام مباشر
1. افتح ملف `index.html` في المتصفح
2. استخدم التطبيق مباشرة!

### الطريقة 2: خادم محلي
```bash
# باستخدام Python
python -m http.server 8000

# باستخدام Node.js
npx serve

# ثم افتح: http://localhost:8000
```

## 💾 التخزين المحلي

يستخدم التطبيق LocalStorage لحفظ:
- ✅ المهام المكتملة
- 💧 حجم المسبح
- 📅 الأسبوع المحدد

## 🎯 كيفية الاستخدام

### 1. إدخال حجم المسبح
- اذهب إلى **الحاسبة** 🧮
- اضغط على "تعديل حجم المسبح"
- أدخل الحجم بالطن (متر مكعب)

### 2. تتبع المهام
- اذهب إلى **الرئيسية** 🏠
- اختر الأسبوع من **الأسابيع** 📅
- أشّر على المهام المكتملة ✅

### 3. عرض الإحصائيات
- اضغط على 🔔 للإشعارات
- شاهد التقدم في الصفحة الرئيسية

### 4. الإعدادات
- اذهب إلى **الإعدادات** ⚙️
- شاهد معدلات الاستهلاك
- أعد تعيين المهام عند الحاجة

## 🔧 التخصيص

### تعديل معدلات المواد الكيميائية
في ملف `app.js`:

```javascript
DOSAGE_RATES: {
    'CLR 90': 2.6,          // عدّل القيمة هنا
    'CLR 90 (Shock)': 5,
    'TIRA POOL 40': 2.4,
    'CLEAR POWER': 5.2
}
```

### إضافة مهام جديدة
في ملف `app.js` - قسم `TASKS_TEMPLATES`:

```javascript
{ 
    week: 1, 
    day: 'السبت', 
    time: '9:00 AM', 
    product: 'CLR 90', 
    pump: '6 ساعات', 
    wait: '6-12 ساعة', 
    notes: 'التطهير الأسبوعي' 
}
```

### تغيير الألوان
في ملف `style.css`:

```css
:root {
    --primary: #3B82F6;     /* اللون الأساسي */
    --success: #22C55E;     /* لون النجاح */
    --warning: #F59E0B;     /* لون التحذير */
    --danger: #EF4444;      /* لون الخطر */
}
```
